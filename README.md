# AI Financial Insights Hub

An intelligent financial tracking and analysis platform that processes transaction data and generates automated financial insights using AI.

🚀 Tech Stack
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **AI Integration:** Google Gemini API, Claude AI
- **Data Processing:** Pandas, NumPy

🛠️ Project Structure
- `backend/` - Core API logic (FastAPI)
- `database/` - PostgreSQL schema and migrations
- `scripts/` - Data processing tools
